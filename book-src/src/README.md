# Intrepid Explorer — Line Follower & Maze Solver

Welcome! Over the next several weeks you will build a hardware line-following
robot capable of solving a maze, starting from programming fundamentals and
working up to closed-loop control and maze-solving logic.

| Task | Topic | Duration |
|---|---|---|
| 1 | Programming Fundamentals (C++) | 2 weeks |
| 2 | Introduction to Arduino | 1 week |
| 3 | Understanding the Bot — Sensors & Actuators | 1 week |
| 4 | Bang-Bang Line Following and P Controller | 1 week |
| 5 | PD / PID Control | 1 week |
| 6 | LSRB / RSLB Maze Logic | 1 week |
| 7 | Competition | — |
