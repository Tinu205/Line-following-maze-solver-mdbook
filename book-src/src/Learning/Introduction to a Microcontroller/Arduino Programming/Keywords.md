# Keywords

## What are Keywords?

* Keywords are reserved words with specific meanings and purposes within the language. They're predefined building blocks that serve essential functions in your code.
* Keywords cannot be used as variable names.
* Keywords are case-sensitive.

## 1. Structure Keywords

* **Define the overall structure of your program:**
  * `setup()` : Runs once at the beginning.
  * `loop()` : Runs repeatedly after setup.
* **Control program flow:**
  * `if`, `else`, `switch`, `case`, `for`, `while`, `break`, `continue`, `return`

## 2. Data Type Keywords

* **Specify the kind of data a variable can hold:**
  * `int` : for integers
  * `float` : for decimal numbers
  * `boolean` : for true/false
  * `char` : for single characters
  * `String` : for text
  * `void` : for functions returning no value

## 3. Value Keywords

* **Represent specific values:**
  * `true`, `false`, `HIGH`, `LOW`, `INPUT`, `OUTPUT`

## 4. Other Keywords

* **Perform various tasks:**
  * `pinMode()`, `digitalWrite()`, `analogRead()`, `analogWrite()`, `delay()`, `Serial.begin()`, `Serial.println()`, `sizeof()`, `struct`, `class`, `public`, `private`, `protected`
