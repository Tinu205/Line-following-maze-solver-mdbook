## Arduino programming

### About Arduino programming
Arduino microcontrollers are programmed using the Arduino IDE (Integrated Development Environment). It runs on Windows, Mac OS X, and Linux.

Arduino programs are called 'sketches' which are written in a high-level programming language based on C and C++.

A sketch is a set of C++ functions. The Arduino IDE passes them to a C++ compiler (avr-g++), which turns them into code the board can run.
