# Task 4: Assignment

## Part A: Bang-Bang

Implement a bang-bang line follower: full correction one way when the sensor sees the line drift left, full correction the other way when it drifts right. Run it on the actual line and notice the wobble.

## Part B: P Controller

Implement a P controller instead, correction proportional to how far off the line you are, and try a few different `Kp` values. Notice how too low a `Kp` barely reacts, and too high a `Kp` overshoots and oscillates.
