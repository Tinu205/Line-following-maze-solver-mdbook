# Task 2: Assignment

Same simulator, new skill: instead of just reading and running code, you're wiring up real circuits and watching them respond. Since there's no auto-grading site for hardware the way HackerRank auto-judged Task 1, you'll submit a short video for each sub-task instead.

## What to build

1. **Traffic Light** (digital I/O) — three LEDs (red, yellow, green) that cycle on and off in sequence, each held for a fixed delay, using `digitalWrite()` and `delay()`.
>Note: To change the color of led after adding it to the sketch area right click on it and and under properties change the color option.

2. **Blinking LED on command** (Serial communication) — an LED that only turns on or off when you send a command through the Serial Monitor.

3. **LED brightness** (PWM) — smoothly fade an LED up and down using `analogWrite()`.

4. **Potentiometer-controlled brightness** (analog input) — read a potentiometer with `analogRead()` and use that value to set the LED's brightness in real time.


## How to record your video

For each sub-task, record one short screen capture (30–60 seconds), such that the following are visible:

1. **The code** — show the sketch you wrote, scrolled so it's actually readable.
2. **The wired circuit** — show the Velxio circuit view with all your connections visible.
3. **The simulation running** — hit ▶ and let it run long enough to clearly show the behaviour described above: the traffic light cycling, the LED responding to your typed command, fading smoothly, or tracking the potentiometer live.


Not sure what this should look like? Here's a [sample submission video](https://youtu.be/9G3R0EMmaKU) showing the Blinking LED example recorded in the expected format.
