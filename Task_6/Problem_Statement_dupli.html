Intrepid Explorer Edition 3

Image Processing: Problem Statement

The village is decorating for the Great Harvest Festival, and DharaBot has been put in charge of sorting the festival ornaments! Along the path, colorful gates lie one after another.
DharaBot must look, identify the gate’s color, and take the correct turn to place each decoration in its respective zone. With three ornaments left before sunset, DharaBot must stay sharp to help light up the festival night!

It’s time to apply image processing skills we have learned so far and assist our intrepid explorer in its visual adventure!

  • The aim of this task is to reach the other end of the arena while going through the correct coloured gates!
  • When the simulation starts, a timer of 60 seconds will automatically begin.
  • A new waypoint will appear every time the robot collects a waypoint until it reaches the end of the arena.
  • The timer will stop either when the robot reaches the waypoint count or when it collides with a wall.

Note: You need to store the list of colour intially and then go through the gates according to the list

Arena

The Arena is such designed that if you don’t choose the right door you end up in water and crocodiles eat the e-puck

Scoring

The run shall be evaluated primarily on two parameters

  1. Correct Doors went Through: This represents the number of waypoints you captured along the way. The run is automatically considered complete when you collect the last waypoint at the starting of the free zone. Remember that you cannot collect the next waypoint before collecting the current one.

  2. Time remaining: This represents the time remaining out of the total time of 60 seconds after the run started. The remaining time would automatically be considered 0 if the robot collides with any wall.

$$ \text{total_score} = \left( \frac{\text{waypoints_reached}}{Total\_waypoints} \times 100 \right) + \left( \frac{\text{remaining_time}}{60} \times 100 \times \frac{\text{waypoints_reached}}{100} \right) = \text{300} $$ $$ \text{Bonus 50 marks, if all waypoints_reached = 100} $$

A guide to completing the task

  1. Make sure that you are comfortable in using Opencv with webots. It is highly recommended that you complete the prior tasks before implementing this one. Participants are also recommended to go through the Learn section for each task and perform the Challenge activities.
  2. The essential setup (world, robot and the visualisation of Waypoints) along with the evaluator is provided to you.
    • You can find the download link for the zip that contains the required files in the Downloads section.
  3. Unzip the downloaded ZIP file. This can be done by right clicking the downloaded ZIP file and clicking “Extract all” on Windows and “Extract here” on Ubuntu.
  4. Navigate inside the extracted folder and open the teaminfo.json file with the text editor of your choice.
  5. Edit the teaminfo.json file by replacing 1234 in “IE#1234” against the team_id by your own team ID.
  6. Save the teaminfo.json file.
  7. Navigate to the controllers folder in the Task folder, then navigate to the e-puck folder. Here, you’ll find a file called e-puck.py. This is the file that must be edited to reflect your algorithm to implement the task.

Note : Do not modify the e-puck-supervisor.py, E-puckDistanceSensorSRC.proto , E-puckGroundSensors.proto and E-puck-eYSRC.proto file and also do not change the directory structure that is provided.
